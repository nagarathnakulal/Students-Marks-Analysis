# Students-Marks-Analysis
Python for Data Science Week 1 – Student Marks Dataset Analysis using Pandas and NumPy.


## 📌 Project Overview

This project is part of **Week 1 – Python for Data Science Basics**.
The project focuses on analyzing a student marks dataset using **Python, Pandas, and NumPy**.

## 🎯 Objective

The main objective is to learn basic data analysis and data cleaning techniques using Pandas and NumPy.

## 📂 Dataset

The dataset contains student information and scores, including:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Google Colab

## 🔍 Tasks Performed

* Loaded the CSV dataset using Pandas
* Checked for missing values
* Handled missing values using `fillna()`
* Calculated mean, median, and mode
* Found minimum and maximum scores
* Calculated the average score of each student
* Sorted students based on their average scores
* Used NumPy for basic statistical calculations

## 📊 Project Outcome

The project demonstrates basic skills in **Python for Data Analysis**, including data loading, cleaning, statistical analysis, and sorting using Pandas and NumPy.
